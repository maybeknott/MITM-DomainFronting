# Intelligent automation

This project ships small automation layers that reduce manual triage: profile selection, evasion lab prep, eBPF hooks, and one-shot lab evidence.

## Commands

| Command | Purpose |
|---|---|
| `python main.py advise` | Context-aware recommendations (profiles, evasion lab, JA3, eBPF) |
| `python main.py advise --text` | Same, human-readable |
| `python main.py lab-prepare` | Regenerate evasion profiles + smoke checks + lab evidence bundle |
| `python main.py probe` | Readiness JSON now includes an `intelligent` object |
| `python scripts/apply_strategy_profile.py --remember` | Persist last successful profile to `.local-state/strategy-winner.json` |

## Advisor inputs

The advisor reads local, redacted state only:

- `.local-state/decision-report.latest.json` (failure labels, phase classification)
- `.local-state/strategy-winner.json` (remembered profile)
- Presence of `Xray-config/MITM-DomainFronting.evasion-*.json` lab profiles
- Optional readiness probe fields (config sync, JA3 configured vs measured)

It does not upload data or change system proxy settings.

## Evasion lab profiles

Generated by `scripts/generate_evasion_profiles.py` (also run from `config-src` build when `--generate-profiles` is used):

| Profile | Use when |
|---|---|
| `evasion-fragment` | TLS/DPI blocking or static JA3 labels |
| `evasion-reality-stub` | REALITY-style path experiments (lab) |
| `evasion-tun-stub` | TUN inbound stub for route tests |
| `evasion-fakedns` | DNS trap / FakeDNS lab |
| `evasion-high-stealth` | Combined fragment + FakeDNS + TUN stub |

Import these only in controlled lab environments. They are not the default user workflow.

## Lab prepare pipeline

`main.py lab-prepare` runs, in order:

1. `generate_evasion_profiles.py`
2. `protocol_smoke.py --scenario ja3-pool-attach`
3. `protocol_smoke.py --scenario ebpf-xdp-loader` (simulate on non-Linux)
4. `lab_evidence_run.py` + `lab_evidence_validate.py` (unless `--skip-evidence`)

Use `--allow-warn` when wire-level Suricata proof is not available on the host.

## eBPF (Linux lab)

With explicit consent:

```bash
MITM_EBPF_CONSENT=1 python scripts/ebpf_xdp_loader.py --program telemetry --interface eth0
MITM_EBPF_CONSENT=1 MITM_EBPF_CONTAINMENT=1 python scripts/ebpf_xdp_loader.py --program containment --interface eth0
```

Process supervisor hooks update containment map liveness when core starts/stops.
