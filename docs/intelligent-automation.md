# Intelligent automation

Local automation reduces manual triage: persona playbooks, context-aware advisor, profile memory, evasion lab prep, eBPF hooks, and lab evidence bundles. **No data leaves your machine** unless you export artifacts yourself.

## Entry points

| Surface | What it does |
|---------|----------------|
| `main.py onboard` | Runs a persona playbook + builds advisor plan |
| `main.py advise` | Advisor only (`--text` for console) |
| `main.py probe --json` | Readiness + `intelligent` object |
| `main.py lab-prepare` | Evasion regen + protocol smoke + lab evidence |
| GUI **Smart Tips** | Same advisor plan as `advise` |
| GUI **Apply Recommended** | Strategy profile + optional `remember_winner` |

## Personas and playbooks

Personas select which automated steps run in order. The advisor **infers** a persona when you do not pass `--persona` (from failure labels, lab profile presence, release readiness).

| Persona | Audience | Typical steps |
|---------|----------|----------------|
| `newcomer` | First setup | validate config → static preflight → probe → advise |
| `maintainer` | Repo/CI | audit → release-check → config-src validate → regen profiles |
| `lab` | Evasion evidence | evasion profile gen → protocol smoke → lab evidence validate |

### Commands

```powershell
py -3 main.py onboard
py -3 main.py onboard --persona maintainer
py -3 main.py onboard --persona lab --dry-run
py -3 scripts/onboard.py --json-out .local-state/onboard-report.json
```

Implementation: `scripts/core/automation_playbook.py` (`PLAYBOOKS`, `run_playbook`, `infer_persona`).

## Intelligent advisor

`scripts/core/intelligent_advisor.py` builds a ranked plan:

- **Inputs (local only):** `.local-state/decision-report.latest.json`, `.local-state/strategy-winner.json`, evasion profile files on disk, readiness fields (config, listener, trust, page check, JA3, release).
- **Outputs:** `persona`, `failure_labels`, `recommendations[]` (priority, title, detail, command, doc link), `suggested_profile`, `playbook`, `automation_commands[]`.

```powershell
py -3 main.py advise --text
py -3 main.py advise --persona lab
py -3 scripts/intelligent_advise.py --persona newcomer --no-persist
```

When `persist=True` (default for `onboard` and GUI), the plan is written to:

`.local-state/advisor-plan.latest.json`

Review this file before sharing; it is redacted but may contain local paths.

### Readiness-driven recommendations (examples)

| Signal | Typical P0/P1 action |
|--------|-------------------------|
| Config invalid | Repair primary JSON |
| Listener not loopback-only | Rebind inbound to `127.0.0.1` |
| Trust not aligned | Generate CA + manual install |
| Page check failed | Health probe; install Playwright if missing |
| Release blockers | `release-check` / regen profiles |
| DPI / JA3 labels | Suggest evasion lab profile (lab only) |

## Strategy winner memory

After a successful profile application:

```powershell
py -3 scripts/apply_strategy_profile.py --profile balanced --remember
```

GUI **Apply Recommended** can set the same flag. Stored at `.local-state/strategy-winner.json` and surfaced in advisor output.

## Evasion lab profiles

Generated by `scripts/generate_evasion_profiles.py` (also from `config-src` build with `--generate-profiles`):

| Profile | Use when |
|---------|----------|
| `evasion-fragment` | TLS/DPI blocking or static JA3 labels |
| `evasion-reality-stub` | REALITY-style path experiments (lab) |
| `evasion-tun-stub` | TUN inbound stub for route tests |
| `evasion-fakedns` | DNS trap / FakeDNS lab |
| `evasion-high-stealth` | Combined fragment + FakeDNS + TUN stub |

Import only in controlled lab environments. Not the default user workflow.

## Lab prepare pipeline

`main.py lab-prepare` runs, in order:

1. `generate_evasion_profiles.py`
2. `protocol_smoke.py --scenario ja3-pool-attach`
3. `protocol_smoke.py --scenario ebpf-xdp-loader` (simulate on non-Linux)
4. `lab_evidence_run.py` + `lab_evidence_validate.py` (unless `--skip-evidence`)

Use `--allow-warn` when wire-level Suricata proof is not available on the host.

## eBPF (Linux lab)

With explicit consent:

```bash
MITM_EBPF_CONSENT=1 python scripts/ebpf_xdp_loader.py --program telemetry --interface eth0
MITM_EBPF_CONSENT=1 MITM_EBPF_CONTAINMENT=1 python scripts/ebpf_xdp_loader.py --program containment --interface eth0
```

Process supervisor hooks update containment map liveness when core starts/stops.

## Wire proof and JA3 automation

| Script | Role |
|--------|------|
| `scripts/wire_proof_suricata.py` | Suricata/PCAP-oriented lab proof |
| `scripts/core/ja3_pool_attach.py` | Attach `pool_id` from `config-src/ja3-profile-pools.yml` |
| `scripts/generate_profiles.py` | Operating profiles + JA3 wiring |

## CI integration

`.github/workflows/validate.yml` runs evasion regen, smoke tests, and advisor smoke so automation stays wired. Local equivalent: `py -3 main.py onboard --persona maintainer --dry-run` then `main.py test`.
