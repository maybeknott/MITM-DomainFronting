# شروع سریع MITM-DomainFronting

این راهنما مسیر کوتاه و امن برای اجرای پروژه است. برنامه هیچ گواهی‌ای را بی‌صدا در سیستم نصب نمی‌کند و تنظیمات پروکسی سیستم را بدون اجازه تغییر نمی‌دهد.

## مسیر پیشنهادی

1. برنامه را اجرا کنید:

```powershell
py -3 main.py gui
```

2. در Dashboard فقط به وضعیت کلی و دکمه اصلی توجه کنید. برنامه بهترین اقدام بعدی را نشان می‌دهد.

3. اگر گواهی محلی وجود ندارد، `Generate Local CA` را بزنید. کلید خصوصی فقط روی همین دستگاه می‌ماند.

4. اگر Xray Core موجود نیست، `Download Xray Core` را اجرا کنید.

5. اگر هشدار `Unsafe listener exposed` دیدید، ابتدا کلاینت خارجی مثل v2rayN را طوری تنظیم کنید که فقط روی `127.0.0.1` گوش کند.

6. بعد از آماده شدن هسته، `Run Page Check` را اجرا کنید. این تست یک مرورگر معمولی را از مسیر پروکسی محلی بررسی می‌کند.

7. فقط بعد از موفق شدن Page Check، در صورت نیاز `Fingerprint Check` یا اعتبارسنجی JA3 را اجرا کنید.

## دستورات مفید

```powershell
py -3 main.py probe --json
py -3 main.py test
py -3 main.py release-check
```

## معنی وضعیت‌ها

- `Ready`: مسیر پایه آماده تست مرورگر است.
- `Needs Attention`: یک مورد قابل اصلاح وجود دارد.
- `Blocked`: ادامه دادن امن نیست؛ ابتدا هشدار اصلی را برطرف کنید.

## نکات امنیتی

- گواهی و کلید خصوصی را منتشر نکنید.
- اگر پورت `10808` روی `0.0.0.0` یا `[::]` باز بود، وضعیت آماده محسوب نمی‌شود.
- تله‌متری شبکه در برنامه، مگر خلافش صریحا نوشته شود، از شمارنده‌های کلی سیستم می‌آید و ترافیک Xray را به‌صورت جداگانه اندازه نمی‌گیرد.
